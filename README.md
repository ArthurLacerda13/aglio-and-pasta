## 🇧🇷 Português

### 📌 Sobre o Projeto
O **Aglio & Pasta** é uma aplicação web moderna e elegante projetada para um restaurante fictício de gastronomia italiana refinada. O site combina design de alta qualidade, animações suaves e interatividade fluida para oferecer uma experiência imersiva ao usuário.

> **Nota:** Este projeto é **exclusivamente uma demonstração frontend** desenvolvida para fins de estudo e portfólio.

### ✨ Principais Funcionalidades
- 🌍 **Suporte Multilíngue (i18n):** Troca dinâmica de idioma entre Português, Inglês e Italiano.
- 🌓 **Tema Claro & Escuro:** Alternância de tema com preferência salva localmente.
- 📜 **Cardápio Interativo:** Exibição detalhada de pratos, ingredientes e promoções.
- 🍷 **Módulo de Reserva:** Interface para simulação de reserva de mesas.
- 🎨 **Animações Fluidas:** Efeitos visuais refinados com AOS (Animate On Scroll).
- 📱 **Design Responsivo:** Layout adaptado para mobile, tablet e desktop.

## 🚀 Como Executar o Projeto / How to Run / Come Eseguire

### Prerequisitos / Prerequisites / Prerequisiti
- **Node.js** (v18.x ou superior)
- **NPM** (v10.x ou superior)

### Passo a Passo / Step by Step / Guida Passo-Passo

1. **Clonar o repositório / Clone the repository:**
   ```bash
   git clone https://github.com/ArthurLacerda13/aglio-and-pasta.git
   cd aglio-and-pasta
   ```

2. **Instalar as dependências / Install dependencies:**
   ```bash
   npm install
   ```

3. **Iniciar o servidor de desenvolvimento / Start dev server:**
   ```bash
   npm run dev
   ```

4. **Acessar no navegador / Open in browser:**
   Navegue para `http://localhost:5173` (ou porta indicada no terminal).
